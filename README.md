# ALS CNS Biomarker Panel

Reproducibility code for an **in-silico biomarker-discovery study** of amyotrophic
lateral sclerosis (ALS) using post-mortem central-nervous-system (CNS) RNA-seq.
A LightGBM + SHAP pipeline defines a **25-gene CNS panel** that distinguishes
ALS-spectrum motor neuron disease from non-neurological controls. Nine external CNS
datasets validate it (zero-shot and by pooled cross-validation) and are pooled to trim
it to a **nine-gene critical panel**. The critical panel is then characterised with
cell-type composition, single-nucleus and spatial data, cross-disease comparisons,
bulk direction-of-change meta-analysis and direction-matched drug annotation.

> **Discovery cohort:** GSE153960 (NYGC ALS Consortium, n = 874 post-mortem CNS).
>
> **Disclaimer:** All analyses are computational. Findings are *associative* and
> require experimental validation; nothing here is clinical advice.

## Setup

```bash
conda env create -f reproduce/environment_als.yml
conda activate als-cns-panel
```

Depends only on the standard scientific-Python stack (numpy, pandas, scikit-learn,
lightgbm, shap, scipy, statsmodels, matplotlib, h5py).

## Data

Expression data are public and are **not** stored here. Download into `resources/`:

```bash
bash reproduce/download_geo_data.sh        # GEO cohorts → resources/
bash reproduce/quantify_srp064478.sh       # (optional) SRP064478 Salmon quantification
```

The two single-nucleus cortex cohorts (GSE219280, GSE212630) are fetched by hand (see
`reproduce/README.md`, Provenance). The Pineda 2024 cortex atlas needs a free Synapse
account and a Personal Access Token in `~/.synapseConfig`:

```bash
python reproduce/download_synapse_pineda.py   # optional; steps 41d/41f skip without it
```

## Reproducing the analysis

```bash
bash reproduce/run_all.sh          # full pipeline
bash reproduce/run_all.sh fast     # skip the feature-matrix rebuild (needs it cached)
bash reproduce/run_all.sh from 24  # resume from a given step
```

`reproduce/FIGURE_MANIFEST.md` maps every figure and table to its producing script,
so any single result can be regenerated without running the whole pipeline.

### The feature matrix (`lgbm_prefilter_X.npy`)

The pre-filtered feature matrix (874 × 47,822, ~160 MB) is **not** tracked here.
Step 2 (`src/lgbm_iterative_pipeline.py`) builds it from GSE153960 and caches it as
`src/lgbm_prefilter_X.npy`, which every later step reads. The rebuilt matrix is
identical, value for value, to the one the study used.

## Model configuration

A Bayesian search evaluated candidate preprocessing, feature-selection and classifier
configurations by cross-validation on the discovery dataset (874 GPL24676 samples, top 500
SHAP-ranked genes) and selected the following pipeline: remove constant columns, keep the
genes that carry 99.9% of a LightGBM model's cumulative gain, and classify with LightGBM.
`utils.selected_pipeline()` implements that pipeline with scikit-learn and LightGBM, and
`utils.SELECTED_LGBM_PARAMS` holds its classifier's hyperparameters. Every analysis uses that
classifier on gene sets fixed by the study design, with two documented rules for refits:
the minimum leaf size stays the same fraction of each training set, and the per-tree
feature fraction keeps the same number of genes per tree on smaller panels. The search
itself is not part of this repository.

## Data availability

Accessions used by the scripts: **GSE153960** (discovery and the donor-disjoint
GPL16791 samples); external CNS datasets GSE76220, GSE122649, SRP064478, GSE255683,
GSE287256, GSE26927, E-MTAB-8635 and E-MTAB-2325; single-nucleus GSE287257, GSE190442
(reference atlas), GSE219280, GSE212630 and Synapse syn51105515; spatial GSE288365;
cross-disease GSE64810, GSE13162, GSE125583 and GSE68719; blood GSE234297; regional
GSE67196.
